## 2024-05-24 - [Add React.memo to prevent unnecessary re-renders]
**Learning:** In a long list of items (like conversations in `conversation-list.tsx`), passing complex objects or non-primitive props (like translation function `t`) will cause all items to re-render when the parent component re-renders, even if the item data itself hasn't changed. This is a common performance bottleneck in React lists.
**Action:** Use `React.memo` for list items (e.g., `ConversationItem`), and provide a custom comparison function that specifically omits non-primitive props like `t` from the comparison, knowing that if `t` changes, the app likely remounts completely. This prevents unnecessary re-renders when parent state (like search filter, scroll position, or active item changes) updates.
