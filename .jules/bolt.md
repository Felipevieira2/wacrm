## 2024-05-19 - [O(n) Array Reversal inside useMemo on Large Arrays]
**Learning:** In `src/components/inbox/message-thread.tsx`, checking for the last customer message was previously implemented with `[...messages].reverse().find(...)`. This shallow-copies the array, reverses the copy, and finds the first match, resulting in an O(n) memory allocation and operation on every dependency change inside the `useMemo`. Since the messages array updates frequently in real-time, this incurs unnecessary garbage collection pressure and CPU overhead on large threads.
**Action:** Always prefer using `Array.prototype.findLast()` to traverse arrays backward without triggering O(n) array copy and reverse operations, particularly in React components dealing with large dataset computations.
