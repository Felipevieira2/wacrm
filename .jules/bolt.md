## 2023-10-05 - Safe Memoization with Next-Intl
**Learning:** When using `React.memo` on components rendered in large lists (like `ConversationItem`), and the component receives the `t` translation function (from `next-intl`), passing `t` directly as a prop breaks memoization if standard strict equality checks are used for all props. However, omitting `t` by statically listing all other props is a major anti-pattern that creates maintainability issues.
**Action:** Use a dynamic custom equality function that shallow-compares all props by iterating through the keys, and explicitly ignores the `t` prop during comparison (e.g., `if (key === 't') continue;`). This is safe because localization changes typically trigger full app re-mounts, making memoization on the `t` prop itself unnecessary.
