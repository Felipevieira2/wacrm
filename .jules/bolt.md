## 2024-05-24 - React.memo with next-intl\n**Learning:** Passing the `t` function from `next-intl` as a prop to memoized components will break memoization because `useTranslations` returns a new function reference on every render.\n**Action:** When using `React.memo`, implement a custom equality function that explicitly omits `t` from the comparison. Add a comment explaining that this is safe since localization changes trigger full app re-mounts.
