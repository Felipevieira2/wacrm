## 2024-06-25 - Prevent O(N) list re-renders on selection change
**Learning:** Found a performance bottleneck where updating the `activeConversationId` at the `InboxPageInner` level caused the entire `ConversationList` (and all `ConversationItem` instances) to re-render. Since `ConversationItem` was not memoized, a single thread selection triggers an O(N) re-render of the list.
**Action:** When rendering long lists where the selection state of one item changes frequently, wrap the individual list item components in `React.memo` with a custom comparison function so only the previously selected and newly selected items re-render. Additionally, cache computationally expensive operations on the parent list (like `groupMessagesByDate` in `MessageThread`) with `useMemo` so they don't fire repeatedly during rendering.
